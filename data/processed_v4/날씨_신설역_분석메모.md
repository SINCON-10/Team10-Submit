# 모델링팀 전달용: 날씨·신설역 분석 메모 (쉽조 전처리, 2026-11-12)

## 1\. 새로 추가된 열 (전처리 v4)

| 열 | 뜻 | 들어간 파일 |
| :---- | :---- | :---- |
| w\_temp / w\_app | 그 시간 기온 / 체감온도 (℃) | 4개 파일 전부 |
| w\_rain / w\_rain3 | 그 시간 강수량 / 직전 2시간 포함 3시간 합 (mm) | 4개 파일 전부 |
| w\_rain\_day / w\_tmax / w\_snow\_day | 하루(6\~23시) 강수 합 / 최고기온 / 적설 합 | 4개 파일 전부 |

## 2\. 날씨가 승차에 주는 영향 (학습 기간, 행사·공휴일·이상치 제외)

기준: 같은 역·시간·요일유형·월의 중앙값 대비 차이.

| 조건 | 승차 변화 |
| :---- | :---- |
| 그 시간 비 0.1\~1mm | \-3% |
| 그 시간 비 1\~3mm | \-7% |
| 그 시간 비 3mm 이상 | \-9% |
| 하루 비 20mm 이상 | \-7% |
| 최고기온 33℃ 이상 | \-2% |
| 눈 오는 날 | \-2% |

- 비 효과는 **출퇴근 시간에 작고(-2\~-5%), 낮 시간(10~~15시)에 크다(-10~~\-16%)**. 출근은 비가 와도 하고, 외출은 줄어드는 패턴.  
- 일요일 낮(10~~11시)은 \-19~~\-20%로 가장 큼.  
- 폭염·눈은 효과가 작음.  
- 비 오는 시간은 전체 행의 약 3%뿐이라, 점수에 주는 영향은 제한적일 수 있음. **효과 크기는 검증 점수로 확인 필요.**
