# 설명서 — 학습, 검증, 변수, 모델 선택, 앙상블 비중, 후처리 계수

최종 예측 C29를 어떻게 만들었고 각 설정을 어떻게 정했는지 설명합니다. 실행 방법은 루트의 `README.md`에 있습니다. 후보별 세부 수치는 `records/candidates_history_README.md`에 있습니다.

모든 예측과 조합은 log1p 공간에서 합니다. 제출할 때 expm1로 되돌리고 0보다 작은 값은 0으로 둡니다.

## 1. 문제를 보는 관점

- 2026-06-30에 서서 7~10월 넉 달(123일)을 한 번에 맞히는 문제입니다. 그래서 어제·지난주 승차 같은 값은 쓸 수 없습니다.
- 팀 전처리(`preprocess.py`)는 과거의 여러 기준일(cutoff)마다 "그날까지만 보고 다음 123일을 맞혀라"는 문제를 쌓습니다.
  - 기준일은 월말이고, 2025-01-15부터 시작합니다.
  - 특징은 그 기준일 이전 자료로만 만듭니다(누수 방지).
- 핵심 기준값은 두 가지입니다.
  - `lvl8`: 기준일 직전 8주 동안 '평범한 날'의 log 승차 평균. 역·시간·요일유형별 평소 수준입니다.
  - `yoy_delta`: 작년 같은 시기(±7일)가 작년 기준일 시점보다 얼마나 높았는지. 계절 변화량입니다.
- 오차 분해(`err_buckets.py`) 결과:
  - 하루 안 시간대별 들쭉날쭉함이 오차의 78%입니다.
  - 20~23시가 오차의 41%입니다.
  - 포아송 잡음 하한은 약 0.092입니다.
  - 그래서 모델을 하나 더 정교하게 만드는 것보다, 여러 모델을 평균해 분산을 줄이는 쪽과 한 번짜리 구조 변화를 고치는 쪽이 효과가 컸습니다.

## 6. 앙상블 비중, 행 배정, 후처리 계수와 결정 방법

### 6.1 세트 안 고정 조합 (C9 방식)

```
Em = (E + C + H) / 3
M  = 0.8·Em + 0.2·A
일반 행:  0.8·M + 0.2·V          행사 행:  M (V에는 행사 성분이 없어서)
3127 행사 없는 날:  A            3127 행사일:  (A + Em) / 2
```

| 비중 | 정한 방법 |
|---|---|
| V 0.2 | 검증 o0227에서 E와 V를 섞어 봤습니다(0.1687 → 0.1675). 행사 행은 V를 빼야 피크가 남았습니다. |
| A 0.2 | 같은 검증에서 0.8·E + 0.2·A가 C3 방식보다 좋았습니다(0.16349). |
| E·C·H 1/3씩 | 셋을 같은 비중으로 평균했습니다. 비중을 맞추지 않았습니다. 세 구간 모두 좋아졌습니다(C4 대비 −0.0018 / −0.0019 / −0.0012). |
| 3127 규칙 | 행사 없는 날은 직접 모델이 10개 월·구간 조합 전부에서 더 좋았습니다(C9 −0.0027 / −0.0022 / −0.0013). |

모델 종류별 비중을 검증으로 맞춘 버전(C20w)도 만들었습니다. 하지만 E·A 모델을 늘린 뒤 다시 맞춰 보니 이득이 없어서(C26 시도) 최종은 고정 비중입니다. 모든 비중은 사람이 고른 고정값이거나 검증에서 정한 값이고, Public 점수로 맞추지 않았습니다.

### 6.4 주말·공휴일 수준 보정과 평일 시간대 보정 (`make_c27.py`, C25c → C29)

**문제:** 토요일·일요일 수준 특징은 8주에 8일뿐이라 잡음이 큽니다. 작년 짝의 계절 변화도 2~3일 평균이라 잡음이 큽니다. 그래서 주말 행은 오차 비중이 가장 컸습니다(행의 33%, 오차의 약 48%).

**보정:** 더 매끄러운 추정값과 모델이 받은 잡음 섞인 값의 차이를 계산하고, 그 차이에 기울기를 곱해 더합니다(log 공간). 계산에는 6/30까지의 승차만 씁니다.

- 주말·공휴일 일반 행:
  - `p += B1·d1 + B2·d2`
  - `d1` = (평일 8주 수준 + 52주 평균의 [요일유형 − 평일] 차이) − 자기 요일유형 8주 수준
  - `d2` = 작년 짝의 평일 계절 변화 − 자기 요일유형의 계절 변화 (±7일 창)
- 평일 일반 행:
  - `p += B3·h`
  - `h` = 직전 시간의 8주 수준 + 52주 평균의 두 시간 차이 − 자기 8주 수준
